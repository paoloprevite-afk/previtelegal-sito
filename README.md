# previtelegal.it

Sito statico degli avvocati Roberto Previte e Paolo Previte. Pubblicato con GitHub Pages dal ramo main.

## Indirizzi delle pagine

Gli indirizzi si scrivono sempre senza `.html` (es. `prima-lettura`, `archivio-novita`, `https://previtelegal.it/modelli-231`): link interni, canonical, og:url e sitemap. GitHub Pages apre comunque il file `.html` corrispondente.
